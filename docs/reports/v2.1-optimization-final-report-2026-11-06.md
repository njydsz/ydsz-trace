## 二、V2.2 增强（本轮新增）

### 2.1 BM25+向量 RRF 混合检索（FR-402）

- **文件**：`pkg/search/bm25.go`、`pkg/search/bm25_test.go`
- **功能**：
  - BM25 倒排索引（支持中英文混合分词）
  - RRF 融合算法（k=60）
  - 混合检索入口 `HybridSearch`
  - 线程安全（sync.RWMutex）
- **接入**：`logs/controllers/logs/semantic_search.go` 增加 `bm25FallbackSearch` 降级路径
- **测试**：5 个测试用例全部通过（分词、BM25 检索、RRF 融合、混合检索、并发安全）

### 2.2 采集位点管理（FR-102）

- **文件**：`pkg/source/offset.go`（已有实现，本轮修复平台兼容性）
- **功能**：
  - inode + offset 双键位点持久化
  - 文件轮转检测（inode 变化 → 从 0 开始）
  - 文件截断检测（size 变小 → 从 0 开始）
  - 原子写入（临时文件 + rename）
- **修复**：Windows 平台兼容性（`syscall.Stat_t` → `platformInode` 跨平台实现）

### 2.3 多行日志合并（FR-104）

- **文件**：`pkg/source/multiline.go`、`pkg/source/multiline_test.go`
- **功能**：
  - 堆栈日志合并（起始行 + 续行 → 单事件）
  - 最大合并行数限制（100 行）
  - 最大字节数限制（64KB）
  - 批量合并工具 `MergeLines`
- **测试**：5 个测试用例全部通过
