## 四、遗留建议（V2.2 规划）

1. **异常检测算法升级**：EWMA、周期基线、突变+消失模式
2. **抑制与合并**：同源异常合并、静默窗口
3. **反馈闭环**：误报标记→自动调阈值
4. **背压本地队列**：服务端不可用时落盘缓存
5. **多源接入补齐**：journald + Syslog + HTTP Push
6. **端侧采样 + 资源护栏**：CPU/内存/磁盘/网络四上限
